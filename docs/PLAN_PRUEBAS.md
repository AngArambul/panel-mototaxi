# Plan de pruebas de Mototaxi

La suite Laravel usa la base temporal SQLite en memoria declarada en `phpunit.xml`. El flujo de navegador se ejecuta con una segunda base SQLite desechable y archivos de evidencia identificados. Las comprobaciones de servicios externos se realizan con dobles de prueba, salvo cuando un informe indica expresamente otra modalidad.

El reporte consolidado vincula los casos con [PHPUnit](evidencias/phpunit.txt), [API HTTP local](evidencias/api-http.txt), [webhook HTTP](evidencias/webhook-http.txt), [Node](evidencias/node-test.txt) y [validación local](evidencias/validacion-local.txt).

Las pruebas web verifican redirecciones y errores en sesión. Las pruebas de API usan respuestas JSON y códigos HTTP. En pruebas de autorización, un menú oculto se acompaña de una petición directa al servidor. La evidencia de persistencia muestra estado y campos sintéticos, omitiendo contraseña, huella y tokens.
